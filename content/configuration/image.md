##### Image settings.

* **Image folder**: The folder where images uploaded by merchants are stored. You can only choose folders inside the image folder set in the Media Manager options.

  You do not need to create this folder. When you install or update CM Live Deal and no folder is chosen yet, it creates a `cmlivedeal` folder inside the Media Manager's image folder (usually `images/cmlivedeal`) and chooses it. If the site cannot create the folder, the [Setup card](/dashboard/setup-card/#merchant-image-folder) on the dashboard tells you.
* **Optimised Image Max Width**: The maximum width of optimised images. The default is 600.
* **Optimised Image Max Height**: The maximum height of optimised images. The default is 600.
* **Optimised Image Quality**: The quality of optimised images. The default is 75.
