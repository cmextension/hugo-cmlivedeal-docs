CMLD Merchant plugin has an option for merchant registration page, we need to have this page before setting up the plugin.

In your back-end, you navigate to `Menus` menu item and click on arrow to expand the sub-menu, then select a menu that you want to create the registration page. The screenshots below use the `Merchant Menu` menu.

![/images/menu_registration_menu.webp](/images/menu_registration_menu.webp)

After selecting the menu, you are taken to the list of current menu items in that menu.

![/images/menu_registration_list.webp](/images/menu_registration_list.webp)

You click the `New` button on the toolbar to add a new menu item, then you are taken to the page as the screenshot below.

![/images/menu_registration_create.webp](/images/menu_registration_create.webp)

You click the `Select` button of `Menu Item Type` field to select menu item's type, a popup will be displayed. You select `Registration Form` of `Users'and the popup is closed.

![/images/menu_registration_popup.webp](/images/menu_registration_popup.webp)

You enter the name of this new menu item and then save.

![/images/menu_registration_name.webp](/images/menu_registration_name.webp)

This new menu item is now displayed in your menu item list.

![/images/menu_registration_list_saved.webp](/images/menu_registration_list_saved.webp)
