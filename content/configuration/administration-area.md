##### Settings for the administration area.

* **Show the setup card**: Show the Setup card at the top of the CM Live Deal dashboard. It lists the settings the site still needs and the ones that are already done. You can also hide the card from the dashboard. A hidden card comes back by itself when something new needs to be set up, for example after you enable the Web Services - CM Live Deal plugin. Turn this option back on to show it at any time. See [The Setup card](/dashboard/setup-card/).
* **Show Impressions column in deal list**
* **Show Clicks column in deal list**
* **Show Captured column in deal list**
* **Show Redeemed column in deal list**
