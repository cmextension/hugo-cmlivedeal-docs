The integration with Membership Pro is done by the `Membership Pro - CM Live Deal Integration` plugin. The plugin is installed with the CM Live Deal package but it is **disabled**, because most sites do not sell memberships. Go to System -> Plugins, search for `CM Live Deal` and enable the plugin only if your site sells memberships through Membership Pro. There is no configuration needed for this plugin.
