The tools in CM Live Deal are used to do technical tasks easily without touching the source code or the database.

Only users with the **Configure ACL & Options** permission for CM Live Deal can open Tools. Super Users have it. To give it to another group, open CM Live Deal's **Options**, go to the **Permissions** tab, and set **Configure ACL & Options** to **Allowed** for that group.
