weight: 10
---

* **Joomla! 5.4 or later, or Joomla! 6**: CM Live Deal 4.0 does not work on Joomla! 3, Joomla! 4 or Joomla! 5 versions older than 5.4. Please check [Joomla!'s Technical Requirements](https://manual.joomla.org/docs/next/get-started/technical-requirements/) for more information.
* **PHP 8.1 or later**: Your site must run PHP 8.1 or a newer version. Joomla! 6 itself needs a newer PHP version, so check Joomla!'s requirements too.

CM Live Deal 4.0 does not use jQuery. It uses the Bootstrap 5 scripts that come with Joomla!, and its buttons and badges use Bootstrap 5 class names, so they follow your template's styles. Cassiopeia, the default Joomla! template, uses Bootstrap 5.

If you use CM Live Deal 3.x on Joomla! 4, update Joomla! to 5.4 or later first, then install CM Live Deal 4.0. See [Upgrade](/install-upgrade/upgrade/).
